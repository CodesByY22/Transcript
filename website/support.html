Common Troubleshooting Steps

If you encounter an issue fetching a transcript, here is how to resolve it quickly:

  1. Ensure the video has closed captions enabled: Some videos do not have creator captions or auto-generated subtitles. If YouTube does not provide subtitles for a video, TranscriptKit will display a clear notification.
  2. Refresh the YouTube tab: If you installed the extension while YouTube was already open, reload the tab so the content script can initialize.
  3. Live Streams: Active live streams do not provide static transcripts until the live broadcast concludes and YouTube generates the replay caption file.
  4. Keyboard Shortcut: By default, press Alt+Shift+C to copy transcripts. You can verify or change this anytime in Chrome via chrome://extensions/shortcuts.

Supported YouTube URL Types

TranscriptKit officially supports all YouTube video layouts:

  • Standard Watch Pages (youtube.com/watch?v=...)
  • YouTube Shorts (youtube.com/shorts/...)
  • Completed Live Streams & Premieres (youtube.com/live/...)
  • Embedded YouTube Player pages
