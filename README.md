# TranscriptKit (free)

## Test it
1. Chrome -> `chrome://extensions` -> Developer mode on -> Load unpacked -> pick this folder.
2. Open any YouTube video with captions -> click the TranscriptKit icon.

## Publish
Zip the folder contents (not the folder itself) and upload to the Chrome Web Store.

Title: TranscriptKit - YouTube Transcript & Subtitles
Short: Copy any YouTube transcript in one click. Export clean text, SRT, or Markdown with timestamps and chapters. Free.
